# โรงเรียนกงไกรลาศวิทยา — แดชบอร์ด IoT ตรวจสภาพดินในนาข้าว

หน้าเว็บแสดงค่าความชื้นดิน 4 จุด และค่า pH/NPK จากชุดเซ็นเซอร์เคมีดิน 1 จุด มีโหมดข้อมูลจำลอง แผนผังจุดวัด คำแนะนำอุปกรณ์ และแจ้งเตือนความชื้นต่ำ รองรับรับข้อมูลจาก Arduino ได้ทั้ง USB Serial และ Wi-Fi บนเครือข่ายเดียวกัน โดยบันทึกข้อมูลที่รับไว้ใน SQLite บนคอมพิวเตอร์

เมนู **แนะนำอุปกรณ์** แสดงอุปกรณ์ในโครงงาน 3 รายการ กดการ์ด Arduino UNO R4 WiFi, Soil Moisture Sensor & Module หรือ NPK+pH Sensor เพื่ออ่านหลักการทำงานและแนวทางใช้งาน สเปกของหัววัด NPK+pH ต้องยืนยันกับคู่มือของรุ่นจริงก่อนต่อใช้งาน

แผนผังเซ็นเซอร์ใช้โมเดลแปลงนา 3 มิติจาก `models/rice-field.glb` และต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดตัวแสดงผลโมเดลจาก Google CDN

## เริ่มใช้งานบน Windows

1. ติดตั้ง Python 3 หากยังไม่มี
2. ดับเบิลคลิก `start_dashboard.bat` ในโฟลเดอร์โปรเจกต์ (ไฟล์จะติดตั้ง FastAPI/Uvicorn ให้อัตโนมัติเมื่อยังไม่มี) หรือเปิด PowerShell แล้วติดตั้ง/รัน:

   ```powershell
   cd C:\project\iot_kl
   py -3 -m pip install -r requirements.txt
   py -3 server.py
   ```

3. เปิดหน้า `http://localhost:8000` และคงหน้าต่างเซิร์ฟเวอร์ไว้ตลอดการใช้งาน
4. ดูรายละเอียดและทดลอง API ได้ที่ `http://localhost:8000/docs`

FastAPI รับข้อมูลที่ `POST /api/telemetry`, ตรวจสอบข้อมูลก่อนบันทึกลง SQLite, และให้หน้าเว็บอ่านค่าล่าสุดผ่าน `/api/latest`; ประวัติข้อมูลเรียกดูได้ผ่าน `/api/history`

## Deploy บน Vercel

Vercel ใช้แอป FastAPI ที่ export เป็น `app` ใน `server.py` โดยอัตโนมัติ เมื่อรันบน Vercel ฐานข้อมูล SQLite จะอยู่ที่ `/tmp/telemetry.sqlite3` เพื่อให้ฟังก์ชันเริ่มทำงานได้ แต่ไฟล์ใน `/tmp` เป็นพื้นที่ชั่วคราวและไม่รับประกันการเก็บข้อมูลข้ามการรันหรือการ deploy ดังนั้นเหมาะกับการแสดงหน้าเว็บ/ทดสอบเท่านั้น หากต้องการเก็บข้อมูลเซ็นเซอร์จริงอย่างถาวร ต้องเปลี่ยนไปใช้ฐานข้อมูลภายนอก และปรับ Arduino ให้ส่งข้อมูลไปยัง URL HTTPS ของ deployment

ข้อมูลที่บอร์ดส่งถึงเซิร์ฟเวอร์จะบันทึกเพิ่มใน `telemetry.sqlite3` ภายในโฟลเดอร์โปรเจกต์ ประวัติทั้งหมดจะอยู่เมื่อปิด/เปิดเซิร์ฟเวอร์หรือหน้าเว็บใหม่ การเก็บข้อมูลจะเริ่มหลังเปิดเซิร์ฟเวอร์นี้เท่านั้น ไม่สามารถเก็บช่วงที่ปิดเซิร์ฟเวอร์หรือข้อมูลจำลองได้ อย่าลบหรือย้ายไฟล์ฐานข้อมูลขณะใช้งาน

อย่าเปิด `index.html` ด้วยการดับเบิลคลิก เพราะต้องเปิดผ่านเซิร์ฟเวอร์นี้เพื่อรับข้อมูล Wi-Fi และรองรับการเชื่อมต่อ USB หากใช้ VS Code Live Server ที่พอร์ต `5500` ให้เปิด FastAPI ที่พอร์ต `8000` ค้างไว้ด้วย เว็บจะส่งคำขอ API ไปยัง FastAPI ให้อัตโนมัติ

## เชื่อมต่อง่ายที่สุด: USB Serial

1. เปิดไฟล์ `arduino/dashboard_serial_test/dashboard_serial_test.ino` ใน Arduino IDE แล้วเลือกบอร์ดและพอร์ตให้ถูกต้อง
2. อัปโหลดสเก็ตช์ จากนั้นปิด Serial Monitor/Serial Plotter (ปิดพอร์ตที่โปรแกรมอื่นใช้อยู่)
3. เปิดแดชบอร์ดด้วย Chrome หรือ Edge บนคอมพิวเตอร์เครื่องเดียวกับที่ต่อ USB แล้วกด **เชื่อมต่อ USB** และเลือกพอร์ต Arduino
4. ถ้าเชื่อมต่อสำเร็จ ค่าตัวอย่างจะอัปเดตทุก 2 วินาทีและบันทึกลง `telemetry.sqlite3` ด้วย ต้องเปิดเซิร์ฟเวอร์แดชบอร์ดค้างไว้เพื่อเก็บข้อมูล เปลี่ยน JSON ในสเก็ตช์ให้เป็นค่าจากเซ็นเซอร์ที่อ่านและสอบเทียบแล้ว

รูปแบบที่แดชบอร์ดรับคือ JSON หนึ่งบรรทัดต่อหนึ่งชุดข้อมูล ที่ baud rate `9600`:

```json
{"moisture":[61,55,68,47],"ph":6.4,"n":38,"p":21,"k":67}
```

`moisture` ต้องมีตัวเลข 4 ค่าเรียงตามจุดวัด 5, 10, 15 และ 20 cm; `ph` อยู่ระหว่าง 0–14; `n`, `p`, `k` เป็นตัวเลข 0–100000 ตามหน่วยของโมดูล

## เชื่อมต่อผ่าน Wi-Fi (เช่น ESP32)

ให้คอมพิวเตอร์และบอร์ดอยู่ใน Wi-Fi/เครือข่ายเดียวกัน เปิด `server.py` ตามขั้นตอนข้างต้น แล้วใช้ IP คอมพิวเตอร์ที่แสดงในหน้าต่างเซิร์ฟเวอร์เป็น URL ปลายทาง เช่น `http://192.168.1.50:8000/api/telemetry` หาก Windows Firewall ถาม ให้เลือกอนุญาตเฉพาะ **Private networks** ที่เชื่อถือได้

สำหรับ Arduino UNO R4 WiFi เปิด `arduino/uno_r4_wifi_dashboard/uno_r4_wifi_dashboard.ino` ใน Arduino IDE แล้วแก้ `WIFI_SSID`, `WIFI_PASSWORD` และ `SERVER_IP` ให้ตรงกับเครือข่าย/คอมพิวเตอร์ โดยดู IP จากบรรทัด `Wi-Fi dashboard` ในหน้าต่างเซิร์ฟเวอร์ โค้ดทดสอบหัววัดความชื้นแบบ analog: ต่อ `AO` เข้าขา `A0`, `GND` เข้ากับ `GND` และ `VCC` ตามแรงดันที่ระบุบนหัววัด (แรงดันสัญญาณ AO ต้องไม่เกินข้อกำหนดขา analog ของบอร์ด) อัปโหลดโค้ดแล้วเปิด Serial Monitor ที่ `115200` baud เพื่ออ่านค่าดิบในอากาศ/ดินแห้งและในดินเปียก แล้วนำค่ามาใส่ `DRY_RAW` และ `WET_RAW` ตามลำดับ ถ้าส่งสำเร็จจะเห็น `HTTP/1.1 200 OK` และค่าจะถูกบันทึกลง `telemetry.sqlite3` ทุก 5 วินาที ระหว่างทดสอบหัววัดเดียว ค่าความชื้นเดียวกันจะแสดงซ้ำครบ 4 จุดตามรูปแบบ API และค่า pH/NPK เป็นค่าตัวอย่าง ไม่ใช่การวัดจริง

ตัวอย่างสเก็ตช์สำหรับ ESP32 นี้ใช้ค่าทดสอบคงที่เพื่อเช็กการเชื่อมต่อ ต้องเปลี่ยนค่าทดสอบเป็นค่าที่อ่านจากเซ็นเซอร์จริงก่อนใช้งานจริง:

```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* WIFI_SSID = "ชื่อ-WiFi";
const char* WIFI_PASSWORD = "รหัสผ่าน-WiFi";
const char* SERVER_URL = "http://192.168.1.50:8000/api/telemetry";

void setup() {
  Serial.begin(115200);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) delay(500);
}

void loop() {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(SERVER_URL);
    http.addHeader("Content-Type", "application/json");
    int status = http.POST("{\"moisture\":[61,55,68,47],\"ph\":6.4,\"n\":38,\"p\":21,\"k\":67}");
    Serial.printf("HTTP status: %d\n", status);
    http.end();
  }
  delay(5000);
}
```

ถ้าใช้มือถือ/เครื่องอื่นเปิดแดชบอร์ด ให้เปิด `http://<IP-คอมพิวเตอร์>:8000` (ไม่ใช่ `localhost`) และใช้ URL `/api/telemetry` ของ IP เดียวกันในบอร์ด

## แก้ปัญหาเบื้องต้น

- **หน้าเว็บแสดงข้อมูลตัวอย่างอยู่:** ดูข้อความใต้สถานะบนแดชบอร์ด หากแจ้งให้เปิด `start_dashboard.bat` ให้รันไฟล์นั้นและเปิด `http://localhost:8000`; หากใช้ Live Server ที่พอร์ต `5500` ให้เปิด FastAPI ค้างไว้ด้วย
- **ปุ่ม USB ใช้ไม่ได้:** ใช้ Chrome/Edge บนคอมพิวเตอร์ เปิดผ่าน `http://localhost:8000` และปิด Serial Monitor ก่อนเลือกพอร์ต
- **เชื่อม USB แล้วไม่มีข้อมูล:** ตรวจว่าบอร์ดส่ง JSON หนึ่งบรรทัดต่อชุดข้อมูลที่ `9600` baud และไม่มีข้อความ debug ปะปนใน Serial
- **บอร์ดส่งไม่ถึงเซิร์ฟเวอร์:** ตรวจว่า IP คอมพิวเตอร์ถูกต้อง ทั้งสองเครื่องอยู่เครือข่ายเดียวกัน และ Firewall อนุญาต Private network; Wi-Fi สำหรับแขกหรือการตั้งค่า client/AP isolation อาจบล็อกการติดต่อระหว่างอุปกรณ์
- **ใช้มือถือเปิดหน้าเว็บ:** ใช้ `http://<IP-คอมพิวเตอร์>:8000` ไม่ใช่ `localhost` เพราะ `localhost` บนมือถือหมายถึงตัวมือถือเอง
- **ต้องใช้เน็ตนอกบ้าน:** ตัวอย่างนี้ออกแบบสำหรับเครือข่ายภายในเท่านั้น อย่าเปิดพอร์ตเซิร์ฟเวอร์นี้สู่สาธารณะหรือทำ port forwarding หากต้องการใช้งานระยะไกล ควรวางระบบผ่าน VPN หรือ MQTT broker ที่มี TLS และการยืนยันตัวตน

## ข้อควรทราบเกี่ยวกับเซ็นเซอร์

สเก็ตช์ทดสอบ USB และ Wi-Fi ข้างต้นใช้ค่าคงที่เพื่อทดสอบการส่งข้อมูลเท่านั้น ไม่ได้อ่านฮาร์ดแวร์ หน้าเว็บแสดงค่าตามที่บอร์ดส่งมาโดยไม่แปลงหน่วย มีการประเมิน pH/ความชื้นเบื้องต้นและคำแนะนำทั่วไป แต่ไม่จัดระดับ NPK จากตัวเลขดิบหรือคำนวณอัตราปุ๋ย การทำโค้ดอ่านเซ็นเซอร์จริงต้องทราบรุ่นบอร์ด รุ่นเซ็นเซอร์ และการต่อสายก่อน

เปอร์เซ็นต์ความชื้นต้องปรับเทียบค่าดิบกับสภาพแห้ง/เปียกจริง ส่วนค่า pH และ NPK ขึ้นกับรุ่นโมดูลและวิธีวัด ตรวจสอบแรงดันไฟฟ้าและการป้องกันน้ำตามสเปกก่อนต่อเซ็นเซอร์

## บันทึกวันปลูกและประเมินระยะอัตโนมัติ

เปิดเว็บครั้งแรกแล้วบันทึกวันที่ปลูก/ปักดำเพียงครั้งเดียว ระบบเก็บวันดังกล่าวใน `localStorage` ของเบราว์เซอร์ และคำนวณอายุข้าวใหม่อัตโนมัติเมื่อเปิดเว็บหรือเมื่อวันเปลี่ยน ไม่ต้องเลือกช่วงเดิมซ้ำ ภาพประกอบระยะจะแสดงตามอายุโดยประมาณ:

- ต้นอ่อน: 0–19 วัน
- แตกกอ: 20–49 วัน
- ตั้งท้อง: 50–79 วัน
- ออกรวง: 80–99 วัน
- สุกแก่: 100 วันขึ้นไป (เกณฑ์ปลายระยะอ้างอิง 100–120 วัน)

ช่วงอายุที่ผู้ใช้ให้มาซ้อนทับกัน เช่น ตั้งท้อง 50–100 วันกับออกรวง 80–100 วัน ระบบจึงใช้ลำดับข้างต้นเพื่อให้ได้ผลอัตโนมัติเพียงระยะเดียวต่อวัน ช่วงจริงขึ้นกับพันธุ์ วิธีปลูก และสภาพแปลง ไม่ใช่การวิเคราะห์ภาพหรือการตรวจพบระยะจริงด้วยกล้อง ควรสังเกตต้นข้าวประกอบ เมื่อเกิน 120 วันระบบยังแสดงสุกแก่และเตือนให้ตรวจความแก่/ปรึกษาเจ้าหน้าที่

เปลี่ยนวันปลูกได้จากปุ่ม **แก้วันปลูก** หากเริ่มรอบใหม่ วันปลูกถูกเก็บแยกตามเบราว์เซอร์และเครื่องที่เปิดหน้าเว็บ หากใช้มือถืออีกเครื่อง ให้บันทึกวันปลูกในเบราว์เซอร์เครื่องนั้นด้วย ล้าง site data หรือใช้โหมดไม่ระบุตัวตนจะลบวันปลูกที่บันทึกไว้

แนวทางบนหน้าเว็บเป็นข้อมูลทั่วไปเพื่อช่วยสังเกต ไม่ใช่สูตรให้น้ำหรือปุ๋ยเฉพาะพันธุ์ ระบบประเมิน pH และความชื้นเบื้องต้นจากค่าที่บอร์ดส่ง พร้อมแสดงข้อควรตรวจสอบ ค่าเตือนความชื้น 35% และ 85% เป็นเกณฑ์ตัวอย่าง ต้องปรับหลังสอบเทียบหัววัดกับดินและวิธีวัดจริง หากอยู่ในโหมดสาธิต ค่าทั้งหมดเป็นข้อมูลจำลอง ส่วนค่า N/P/K แสดงตามที่อ่านได้แต่ไม่จัดระดับขาด–เกินอัตโนมัติเมื่อยังไม่ทราบรุ่น หน่วย และวิธีวัด ให้เลือกสถานะ N/P/K จากรายงานผลตรวจดินเพื่ออ่านแนวทางประกอบ อย่ากำหนดอัตราปูนหรือปุ๋ยจากค่าดิบหรือ pH เซ็นเซอร์เพียงอย่างเดียว ให้ยืนยันกับห้องปฏิบัติการหรือหน่วยงานเกษตรในพื้นที่และทำตามฉลากผลิตภัณฑ์
